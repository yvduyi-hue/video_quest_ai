### 1.3 业务逻辑的最小改动

P2 以模板/样式为主，但因验收项必须真实可用，做了 3 处必要修正：

1. **删除视频参数修正**：原代码显式传 `deleteType: '2'`，Polyv 返回 `deleteType illegal`，删除按钮实际不可用。实测显式传 `1` 同样报错；改为**不传 `deleteType`**（官方默认 1：进入回收站），确认文案同步改为“删除后将进入回收站”。
2. **回收站过滤**：Polyv `search-videos` 仍会返回回收站视频（`basicInfo.status = -1`），列表与统计过滤掉这些项，避免删除后刷新又出现。
3. **真实统计**：新增一次 `window.api.quizList()` 读取，用于“互动题目/关联视频”指标；按当前文件夹 vid 过滤，不使用假数据。

未修改：主进程、preload、数据库结构、Polyv 签名、路由、播放器初始化、Phaser 玩法、依赖版本。
